# Contribuir a tuteuve

Gracias por ayudar a crear un reproductor IPTV abierto para Google TV.

1. Revisa los issues y comenta antes de iniciar un cambio amplio para acordar el alcance.
2. Describe el journey afectado, el dispositivo Android TV, la versión de Android y cómo reproducir el problema.
3. No adjuntes listas privadas, URLs con tokens, credenciales ni fragmentos de emisiones. Usa fuentes de prueba que puedas compartir legalmente.
4. Mantén cada pull request pequeño, con capturas del foco de mando cuando cambie la interfaz y pruebas significativas para parsers o reproducción.
5. Indica los formatos/dispositivos realmente comprobados; evita afirmar compatibilidad universal.
6. Mantén el código legible y modular. Usa comentarios para explicar decisiones difíciles, límites de seguridad o comportamiento no evidente; evita repetir lo que el código ya expresa. Incluye pruebas para cambios en parsers, permisos, persistencia y reproducción.
7. No añadas analítica, telemetría, crash reporting automático ni dependencias que envíen datos sin discusión pública y revisión de privacidad. Lee [SECURITY.md](SECURITY.md) antes de modificar fuentes, almacenamiento, red o componentes Android.

Los cambios nuevos de código se proponen bajo la licencia MIT del proyecto. Las fuentes, iconos y demás recursos externos deben incluir atribución y licencia propias.
